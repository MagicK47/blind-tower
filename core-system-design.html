Core System Draft v0.1

盲域判定系统

一套把战斗、开锁、采集、治疗、仪式和潜行统一起来的动作化 RPG 检定机制。 玩家先观察目标，按住后目标与行动区域同时隐藏，凭记忆和预判释放，最后按重叠质量结算。

01

核心判断

它不是小游戏插入

盲域判定应该成为 RPG 的底层交互。攻击、拆陷阱、采药、疗伤和施法只是目标形状、行动形状、运动规律和结算表不同。

观察不限时

玩家回合可以一直观察目标动向，直到自己决定出手。难点来自承诺后目标与范围隐藏、目标继续运动，以及玩家对节奏和空间的预判。

成长不能只加伤害

玩家变强要体现在信息揭示、隐藏残影、手部稳定、预判辅助、行动范围、弱点识别、失败保护和连击节奏上。

内容必须可编辑

每个怪物、事件、武器、技能和 Buff 都由同一组参数描述。编辑器生成的是可校验的数据，而不是写死的特殊逻辑。

02

一次判定的五阶段

观察

目标与真实尺寸预览可见。观察不限时，但高级信息、弱点、危险区和预判线索受角色能力影响。

蓄势

按住鼠标或触屏。目标、鼠标、行动区域隐藏。角色进入不可取消或半可取消状态。

盲操

玩家拖动不可见行动区域。目标可继续移动、闪现、旋转或变形。

释放

松手后瞬间揭示目标当前位置、行动区域、弱点命中、危险触碰。

结算

按重叠质量、部位、属性、装备、Buff 和环境生成结果。

03

统一公式

判定分 = 重叠质量 + 弱点奖励 + 属性修正 + 装备修正 + 技能修正 + Buff修正 - 目标难度 - 环境干扰

这里的“重叠质量”不是只有命中或没命中。它可以来自面积覆盖比例、中心点距离、命中部位、方向角度、释放时机和目标状态。 这让同一个操作可以产生完美、成功、擦中、失败、反噬五档结果。

完美核心弱点命中，额外收益
成功主体命中，正常收益
擦中低收益，可能有代价
失败无收益或消耗资源
反噬碰到危险区，触发惩罚
04

玩家成长轴

观察力

不再增加观察时长，而是提高观察质量：显示更多目标信息、弱点、危险区和下一次移动预兆。

  • 怪物起跳前出现脚印方向
  • 机关旋转轨迹有短暂残影
  • 采集目标显示高品质区域

记忆力

按住后保留目标残影，或让目标隐藏更慢。

  • 0.3 秒淡出残影
  • 上一位置留下墨痕
  • 显示最后移动方向

专注力

减少拖动时的手抖、漂移、呼吸晃动和环境干扰。

  • 攻击区域实际位置更稳定
  • 中毒、恐惧造成的抖动降低
  • 蓄势时间窗口更宽

预判力

给移动目标提供未来位置线索，但不直接显示答案。

  • 短暂显示未来影子
  • 听觉节拍提示跳跃间隔
  • 闪现怪出现符文倒计时

控制力

改变行动区域的移动速度、惯性、转向灵敏度和释放修正。

  • 重武器拖动惯性降低
  • 松手后微修正半径增加
  • 长按时攻击区域不漂移

熟练度

提升特定武器或工具的范围、伤害、完美阈值和特殊效果。

  • 匕首暴击核心更大
  • 长矛线段更长
  • 开锁针危险触发范围降低
05

武器、技能、工具如何统一

匕首

小圆点。难命中，高暴击。适合打弱点和小型目标。

shape: point, coreDamage: high

长矛

细长线。适合预判冲锋、飞行路线和狭长机关。

shape: line, reach: long

大剑

扇形范围。容错高，但边缘伤害低，容易碰危险区。

shape: arc, edgeFalloff: true

战锤

大圆范围。命中容易，前摇长，适合打大怪和破坏事件。

shape: circle, windup: slow

火球

范围法术。中心高伤，边缘低伤，可点燃场景目标。

shape: blast, damageFalloff: true

开锁针

工具也是行动区域。命中齿位成功，碰到警戒区触发陷阱。

shape: needle, dangerSensitive: true
06

Buff 与 Debuff

Buff 不应该只写“命中率 +10%”。更好的做法是修改盲域系统里的具体参数，让玩家感到状态改变了手感。

鹰眼弱点揭示等级 +1，未来影子 +1 帧
稳手盲操阶段漂移 -40%，释放微修正 +8 像素
战意连续成功时行动区域 +6%，完美伤害 +1
恐惧按住后目标残影消失更快，手部随机抖动增加
中毒拖动速度不稳定，长按超过阈值会偏移
黑暗观察阶段目标只显示轮廓，危险区不可见
07

怪物与事件特性

位移难度基线

大多数普通怪物只保留轻微呼吸或几像素漂移；明显移动是敏捷怪、首领与特殊事件的稀缺特性。第一章主要让玩家熟悉尺寸和盲投，不用移动速度制造门槛。

mostly static / authored exceptions

史莱姆

大体积，慢移动，高血量。适合作为新手训练目标。

large / slow / thick

蝙蝠

小体积，节奏跳跃。考验玩家记忆与释放节奏。

small / hop / fragile

野猪

隐藏后直线冲锋。长矛、陷阱、预判类技能更有效。

charge / linear / armor

幽灵

释放前闪现一次。观察力高时能看到符文倒计时。

blink / phase / clue

开锁

目标是锁芯齿位，危险区是警报簧片。工具越好，针尖越稳。

precision / danger / tool

采药

目标是花蕊和根部。完美命中给高品质材料，擦中给普通材料。

quality / fragile / harvest

09

最小 Unity 原型范围

战斗目标

3 个怪物：史莱姆、穴居斥候、野猪。分别验证近乎静止、原地小跳、短距离蓄力。

行动区域

4 个武器：匕首、长矛、大剑、火球。验证点、线、扇、圆。

事件目标

3 个事件：开锁、采药、疗伤。验证非战斗检定也成立。

成长验证

3 个升级：残影延长、范围扩大、拖动稳定。验证变强是否有体感。

10

游戏界面与模式切换

2D 格子探索 / 判定场 移动、探索、战斗目标、事件目标
属性 装备 背包 日志
普攻 技能 技能 道具 互动

探索状态

主区域是 2D 格子地图。玩家移动、调查、触发事件或接敌。右侧显示角色、装备、背包和任务信息；下方显示可用动作。

判定状态

不建议黑屏切小游戏。当前场景变暗或聚焦，目标进入判定场，下方快捷栏仍然保留，玩家从快捷栏把行动范围拖入场景。

回合制战斗

轮到玩家时可以无限观察目标动向。玩家选择行动并拖出承诺线后，目标、鼠标和行动范围隐藏；松手后揭示并结算。敌人回合前期可直接按技能攻击玩家。

11

真实尺寸预览与练习模式

快捷栏图标只能表达“形状”，不能表达真实大小。因此所有行动都必须支持场景内真实比例预览， 让玩家在正式隐藏前知道它相对目标究竟有多大。

悬停场景显示真实尺寸半透明预览，目标仍可见。
按住玩家可以拖动预览，比较范围与目标比例。
拖出承诺线进入正式行动，目标、范围、鼠标隐藏，不可取消。
松手揭示目标当前位置与行动区域，按重叠质量结算。

Practice Mode

练习模式用于建立公平感和手感，不产生正式效果。

  • 不隐藏目标、不隐藏行动范围、不隐藏鼠标。
  • 不消耗回合、资源、耐久，也不造成伤害。
  • 松手后显示“如果这是正式行动，会命中哪里”。
  • 训练场可无限练；战斗内预演只显示范围，不预测隐藏后的未来位置。
12

设计记录约定

稳定结论要入稿

之后聊天里达成的机制结论，不只停留在对话中，要补进这份设计稿，逐步形成可开发的完整规格。

先统一，再扩展

新武器、新怪物、新事件、新 Buff 都优先映射到同一套盲域参数，只有通用参数无法表达时才新增规则。

原型优先验证手感

Unity MVP 先验证拖出承诺线、隐藏目标、真实尺寸预览、练习模式和几种典型目标运动，再扩充剧情和世界。

13

界面差异化原则

传统布局只是骨架

右侧属性面板、底部快捷栏、主场景区域可以保证可用性，但它们本身不构成卖点。最终画面不能停留在“常规 RPG UI 换皮”。

卖点要落在出手仪式

玩家从快捷栏抽出武器/技能，拖过承诺线后世界、目标、范围和鼠标同时隐去。这个瞬间应成为游戏最有辨识度的画面与手感。

UI 要服务盲域主题

界面风格应围绕“观察、记忆、预判、揭示”设计，例如残影、墨迹、测距刻线、目标轮廓、出手轨迹和结果回放。

避免 普通手游式头像血条、密集背包格、发光技能按钮、信息面板堆叠、等距 3D 战棋、小人棋盘、微缩模型感。
强调 2D 冒险场景本身，快捷栏像武器架或法术卷轴，右侧面板默认收敛，只在需要时展开。格子是移动和距离单位，不是战棋棋盘主视觉。
目标 截图第一眼就能看出“这是一个靠盲判出手的 2D 冒险 RPG”，而不是普通 2D RPG，也不是 3D 战棋。
