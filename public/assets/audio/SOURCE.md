# Audio sources

These game-ready MP3 files were converted from the project owner's licensed local sound library.

- `Fantasy_Game_16bit`: movement, interaction, potion, and combat effects.
- `The Complete UI Sound Effects Library` by CelerisLab: feedback, reward, and interface effects.

The original WAV files are intentionally not included. These sounds are licensed for use as part of this game and must not be redistributed as a standalone asset pack.
