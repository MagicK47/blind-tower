Living Design Document · v0.5 · 2026-07-16

失明王座

一款 50 层、固定地图、固定数值、无随机战斗的经典魔塔 RPG。乐趣来自路线规划、资源取舍与可计算的成长，而不是操作检定。

01

当前设计结论

经典魔塔是主体

按格移动、钥匙门、属性晶石、药水、商店、NPC、楼层往返和固定塔图共同构成完整玩法。

战斗完全确定

接敌前显示准确战损；进入战斗后自动交锋。没有拖动、瞄准、随机命中、暴击或隐藏信息。

路线就是操作

玩家真正做出的动作是选择先打谁、先拿什么、何时买属性、哪把钥匙花在哪扇门上。

内容必须数据化

每层地图、怪物、道具、商店、事件和 NPC 都由统一数据描述，后续可以持续用编辑器扩写。

02

核心循环

读图

查看地形、门、钥匙、怪物、商店、楼梯和支路关系。

估价

靠近怪物读取准确战损，比较不同路径的生命与钥匙成本。

决策

选择战斗、绕行、开门、取道具、购物或返回旧楼层。

成长

获得攻击、防御、生命、金币、钥匙和洞察，改变后续最优路线。

推进

抵达下一层，并让之前无法通过的敌人与机关变得可解。

03

战斗公式

勇者每击 = 勇者攻击 - 怪物防御
怪物反击 = max(0, 怪物攻击 - 勇者防御)
回合数 = ceil(怪物生命 / 勇者每击)
总战损 = (回合数 - 1) × 怪物反击

勇者永远先手，最后一击击败怪物后不再承受反击。攻击不高于怪物防御时无法破防；总战损大于等于当前生命时，接敌会被阻止。

无伤勇者防御不低于怪物攻击
可战能够破防且战后至少剩余 1 生命
慎战战损较高，可能应先探索其他支路
挡路生命不足，暂时不能进入战斗
不破防必须先提高攻击
04

战斗信息与演出

接敌前

近处目标面板显示怪物 HP、预计战损和回合数。危险结果使用红色，但不弹出多余确认框。

  • 无法破防明确标红
  • 生命不足时保留怪物
  • 怪物手册按当前属性实时重算

接敌后

进入双方面对面的自动战斗画面，生命条与伤害逐次变化。战斗已由数值决定，不允许撤退。

  • 勇者攻击
  • 怪物反击
  • 长战斗压缩中间回合

快速完成

玩家可以点击“立即完成”跳过演出，但不能改变结算。完整动画保持在约一秒内。

  • 不要求长按
  • 不要求拖动
  • 不依赖鼠标悬停

结算

统一扣除总战损，再给予金币和经验，记录到怪物手册并自动保存。

  • 生命不会因可战战斗降到 0
  • 首领使用同一公式
  • 第 50 层首领触发结局
05

成长与资源

攻击

决定是否破防，并减少敌方反击次数。红晶、商店与武具遗物提供永久提升。

route unlock / round reduction

防御

直接降低每次反击伤害。跨过敌人攻击阈值时会产生明显的无伤收益。

damage per counter

生命

是整座塔共享的路线预算。药水恢复、升级和商店祝福扩充可承受的总成本。

global route budget

金币

由战斗获得，在商店兑换攻击、防御、最大生命或洞察。连续购买价格递增。

adaptive shop sink

钥匙

黄、蓝、红钥匙对应不同稀缺度的门。门后的收益必须能形成明确取舍。

spatial resource

洞察

不再影响战斗动作。每点洞察降低机关的固定生命代价，用于另一条长期成长轴。

event cost -8
初始属性 = 800 生命 / 18 攻击 / 10 防御
每次升级 = +80 最大与当前生命 / +2 攻击 / +1 防御
每段商店库存 = 3 次；单次 +4 攻击 / +4 防御 / +160 最大生命
高塔圣水 = max(360, 最大生命 × 30%)
06

机关与事件

非战斗事件同样遵循“先看成本，再确认结果”。玩家踩到秘匣、祭坛或古井时，会看到奖励和固定生命代价；确认后立即结算，也可以暂时离开。

机关代价 = max(0, 10 + 当前层 × 2 - 洞察 × 8)
古簧秘匣生命换取金币、钥匙或稀有物品
回忆祭坛生命换取洞察或永久属性
月相古井以可预估代价取得恢复类奖励
设计原则无随机、无拖动、无反复试错菜单
07

怪物参数规范

基础字段

ID、名称、图像、色调、生命、攻击、防御、金币、经验、是否首领。

identity / stats / reward

低防高攻

容易快速击杀，但防御不足时反击很痛，鼓励攻击型路线。

glass cannon

高防低攻

攻击门槛明显；一旦破防，提升少量攻击即可大幅减少回合数。

attack checkpoint

低攻高血

检验防御是否已跨过无伤线，常用于守住可回收资源的支路。

defense checkpoint

首领

仍使用同一公式，难度来自综合数值和前置资源规划，而非另设操作规则。

same rules / larger budget

内容校验

生成楼层时自动检查出生点、楼梯可达性、实体重叠和关键资源闭锁。

editor validation
08

五十层内容结构

1-5

低压教学。直冲者可以击败首位守卫，但几乎耗尽生命。

6-10

第一次要求探索支路、拿晶石并使用商店，建立资源不能跳过的规则。

11-15

攻击与防御阈值开始分化，错误强化会明显增加反击次数。

16-20

加入返回旧层与跨层取药，让保留资源成为正式策略。

21-25

支路收益与战损接近，玩家需要比较金币、经验和永久属性。

26-30

机关、钥匙与首领共同消耗生命，单靠等级已不能覆盖错误路线。

31-35

普通怪开始持续磨血，封印守卫检验前一段的商店分配。

36-40

跨过防御线可大幅省血，配装方向比单纯堆最大生命更重要。

41-45

高压资源回收段，要求保留百分比圣水、火药和低战损支路。

46-50

最终精英段；第 50 层只保留两名近卫与王，压力集中在终战。

09

数值平衡基线

难度增长以五层为最小预算单元。规划路线的段内总战损与关底战损都必须逐段上升；但生命、旧层药水、商店和消耗品共同提供至少一条可通关路线。模拟是回归护栏，不代替人工路线试玩。

规划路线关底战损：56 → 240 → 420 → 475 → 780 → 1156 → 1254 → 1302 → 1584 → 2160
规划路线五层总战损：139 → 470 → 551 → 667 → 1029 → 1486 → 2035 → 3341 → 5387 → 7139
完全直冲通过第 5 层后，于第 7 层被属性门槛拦住
规划路线以 400 / 2560 生命通关，常规回复全部耗尽
正常探索可以通关，但后两段会显著消耗药物与生命
自动门槛规划路线终局余血必须处于 5%–35%，十段战损严格递增
10

界面与手机操作

桌面布局

中央方形地图、右侧完整属性与记录、底部工具栏。键盘方向键、WASD 与点击地图均可移动。

手机竖屏

顶部只保留楼层与系统按钮；地图优先；属性与钥匙紧随地图；操作台固定在屏幕最下方。

底部操作台

中央为加大的方向键，左右分别放手册、地图、火药和圣水。方向键支持按住连续移动。

浏览器防误触

游戏区域禁止文本选中、图片拖拽、长按呼出菜单、双击缩放和页面回弹；安全区适配全面屏。

地图点按

点击地图时，按点击位置相对勇者的主轴方向只走一格；不自动寻路，不会因为误触连续穿越路线。

触控原则

所有正式操作都是点按或方向键移动。核心流程不依赖悬停、右键、精细拖动或多指手势。

战斗适配

手机战斗采用左右双角色卡与底部固定结算区，玩家生命、敌人生命、回合和战损始终可见。

声音反馈

移动、开门、拾取、恢复、阻挡、升级与战斗演出使用统一奇幻音效；右上角提供持久化静音开关。

11

内容编辑器边界

扩充内容时优先组合已有规则。新内容应该改变地图关系、数值阈值、资源回报和叙事语境，而不是为每个敌人写独立战斗脚本。

FloorData11×11 地图、出生点、出口、主题、目标与实体列表
MonsterDef战斗数值、奖励、图像与首领标记
ItemDef立即生效的资源或永久成长
NpcDef对话、一次性赠礼与剧情旗标
TrialDef说明、奖励与统一机关代价

13

方向变更记录

已撤销

移动目标、攻击范围拖拽、承诺线、目标隐藏、命中区域、练习模式、专注值和以观察力减速目标。

已替换

所有战斗回到经典魔塔固定公式；冒险机关改为显示固定生命代价后的确认事件。

仍然保留

50 层固定探索、商店、怪物、NPC、物品、钥匙门、回层传送、本地存档与可持续扩写的数据框架。

后续判断

自动曲线已经建立；下一步优先人工验证每段的地图路线是否真的产生预期取舍，再扩写敌人、事件与叙事。
